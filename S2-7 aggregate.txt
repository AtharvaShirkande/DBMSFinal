Create Book Collection with (Title, Author_name, Borrowed_status) as fields. Write Map Reduce Functions for
following requirements.
1. Display Author wise list of books.
2. Display Author wise list of books having Borrowed status as “True”.
3. Display Author wise list of books having price greater than 300

✅ 1. Author-wise list of books

db.Book.aggregate([
  {
    $group: {
      _id: "$Author_name",
      books: { $push: "$Title" }
    }
  }
]);

✅ 2. Author-wise list of borrowed books

db.Book.aggregate([
  { $match: { Borrowed_status: true } },
  {
    $group: {
      _id: "$Author_name",
      borrowed_books: { $push: "$Title" }
    }
  }
]);

✅ 3. Author-wise list of books with price > 300

db.Book.aggregate([
  { $match: { Price: { $gt: 300 } } },
  {
    $group: {
      _id: "$Author_name",
      expensive_books: { $push: "$Title" }
    }
  }
]);
